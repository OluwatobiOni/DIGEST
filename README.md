# DIGEST Trial: Phase 1 Data Preparation and Reporting

# *Description of project*
  This project contains the reproducible R script and associated files for Phase 1 of the DIGEST trial data analysis. The primary goal of this phase is to prepare and clean the raw clinical trial data, integrate it into a master analysis dataset, and generate initial descriptive reports.

### Directories
  *   scripts/ - Contains the main R script for data processing.
      data/ - All data files for the project are stored here.
          data/raw/ - The original, raw CSV files ingested by the script. This folder should not be modified.
          data/clean/ - Individual cleaned datasets generated by the script (e.g., demographics.csv, lab_values.csv, vital_signs_long.csv).
          data/master/ - The final, merged master_dataset.csv ready for downstream analysis.
      output/tables/ - The final descriptive reports and tables for review (e.g., missing_data_report.csv, baseline_demographics_formatted.csv).

### Files
      DIGEST.Rproj - The RStudio project file. Double-click this to open the project and ensure all file paths work correctly.
      code/DIGEST_01_data_cleaning.R - The main R script that performs all data cleaning, merging, and report generation. This is the script you should run to reproduce the project deliverables.
