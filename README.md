# DIGEST Trial

# *Description of project*
  This project contains the reproducible R script and associated files for the Interim Analysis of the DIGEST trial.
  The goal of the trial is to assess whether diet replacement and a digital therapeutic (Habitual Remission Programme) delivered remotely,
  leads to remission and weight loss in T2D patients, providing a more cost and resource effective Total Diet Replacement (TDR) remission programme.
  
### Directories
  *   scripts/ - Contains the three R scripts used to process the data and complete the analysis.
  *   data/ - All data files for the project are stored here.
          data/raw/ - The original, raw CSV files. This folder should not be modified.
          data/clean/ - Individual cleaned datasets generated by the script (e.g., demographics.csv, lab_values.csv, vital_signs_long.csv).
          data/master/ - The final, merged master_dataset.csv ready for downstream analysis.
          data/mice_datasets/ - Imputed datasets
  *   documents/ - Contains the SAP and Trial Protocol 
  *   output/ - The final reports, plots, and tables for review 

### Files
      DIGEST.Rproj - The RStudio project file. Double-click this to open the project.
